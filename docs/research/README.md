# Research

Findings produced by unattended research tasks from
[`../overnight-queue.md`](../overnight-queue.md).

Documents here are **unverified research, not project decisions**. Every claim
should carry a source link, inference should be labelled as inference, and
unresolved questions should be stated rather than smoothed over.

Nothing in this directory changes how the application behaves. If a finding
warrants product work, it goes to `FEATURES.md` as a decision the author makes,
not as a consequence of the research.
